How a machine differentiates something nobody wrote a formula for: break the calculation into tiny steps, then walk backwards multiplying local slopes.

C2 · Week 2 · lesson 14 of 15103 of 177 · 58% of the book

❓Before you read

A network has a million weights. Guess how many times you would have to run it forwards to measure every derivative by nudging — then guess whether that is affordable.

I have committed to an answer

Two million forward passes. Watch for how backprop gets all of them in roughly one backward pass instead.

🎈The idea, in plain words

In plain English

Suppose a chain of gears: turn gear A and it turns B, which turns C, which turns D.

You want to know: if I turn A by one notch, how far does D move? You don’t need to understand the whole machine. You just need each pair: A→B is ×2, B→C is ×3, C→D is ×0.5. Multiply them: 2 × 3 × 0.5 = 3. Turn A one notch, D moves three.

That’s the chain rule, and that’s backpropagation. Every node only needs to know its own little multiplier.

🔧If you have never seen a formula

Tracing a plumbing fault backwards. Water on the floor. Which joint? Follow the pipe back one connection at a time, checking each as you go.

You do not solve the whole system at once. You attribute the problem one link back, then repeat — and that repeated local attribution is exactly what backpropagation is.

🌉If you know a neighbouring field

This is the chain rule, applied mechanically, and the insight is that it is mechanical.

Anyone who has propagated uncertainty through a calculation, or done sensitivity analysis on a spreadsheet model, has done this: each stage passes its sensitivity to the stage before it.

👁One thing to picture

A graph of boxes with arrows left to right, and a second set of arrows going right to left underneath.

Forward: compute the value. Backward: compute how much each node affected the final loss. Two passes over the same graph, and the backward pass costs about the same as the forward one — which is the result that makes training large networks affordable at all.

⚖️Where this really costs something

This is what GradientTape and autograd do, and knowing it changes how you read errors.

“No gradients provided for any variable” means the tape did not see your computation — the graph was broken. That message is unintelligible without this lesson and obvious with it.

So the graph below is what a framework builds for you, and backpropagation is one backwards walk across it.

🔢The maths, decoded

the chain rule — multiply the local slopes along the path — hover or click it
∂J∂wthe slope, at w = ∂J∂d · ∂d∂a · ∂a∂c · ∂c∂w
SymbolSay it out loudWhat it actually is
computation graph“the wiring diagram”Every intermediate value is a node; every arrow is one elementary operation (× or + or exp).
forward pass“left to right”Compute every node’s value and remember it. You need those values on the way back.
backward pass“right to left”Start with ∂J/∂J = 1 and multiply by each node’s local derivative as you go.
local derivative“this node’s own slope”How much this node’s output changes when its input does. For c = w·x it is simply x.

🧮The worked example, on paper

Take w = 3, x = −2, b = 1, y = 2. The graph is c = w·x → a = c + b → d = a − y → J = ½d².

ForwardValueBackwardValue
c = w·x = 3(−2)−6∂J/∂d = d−7
a = c + b = −6+1−5∂J/∂a = ∂J/∂d · 1−7
d = a − y = −5−2−7∂J/∂c = ∂J/∂a · 1−7
J = ½d² = ½(49)24.5∂J/∂w = ∂J/∂c · x14

Check it the slow way: nudge w from 3 to 3.001 and recompute J. You get 24.514, an increase of 0.014 for a nudge of 0.001 — a slope of 14. The chain rule and the brute-force nudge agree, as they must.

The one thing to remember

The magic is the reuse. ∂J/∂a is computed once and then used by everything upstream of a. In a network with a million weights, one backward sweep gets you all million derivatives. Nudging each weight separately would cost a million forward passes.

Say it out loud

Backprop gets every derivative in roughly one backward pass, where nudging each weight would need two per weight. Why is it so much cheaper?

said it — now check

Because the chain rule lets each node reuse the result already computed downstream of it. Nudging recomputes the whole network from scratch for every single weight; backprop computes each shared piece once and passes it back.

🕳Traps

Common trap

Forgetting you need the forward values. The backward pass uses numbers computed during the forward pass (like x, to get ∂c/∂w). That is why training uses far more memory than inference — every intermediate activation has to be kept.

✅Check yourself

For c = w·x with x = −2, what is ∂c/∂w?

−2, which is x. For a product, the derivative with respect to one factor is the other factor.

Why compute derivatives right-to-left instead of left-to-right?

Because there is one output and many parameters. Going backwards from the single J reuses the shared part of every path. Forward-mode would redo that work once per parameter.

What is ∂J/∂J?

1. It is where every backward pass starts.

  2. From quiz question 10 · backpropagation

    Work itPen and paper, real numbers. You do not own a formula until you have pushed numbers through it yourself.

    c = wx, a = c + b, d = a − y, J = ½d2, with w = 2, x = 1.5, b = −0.5, y = 4. Do the forward pass, then the backward pass for ∂J/∂w and ∂J/∂b.

    show the working

    Forward: c = 3, a = 2.5, d = −1.5, J = 1.125.

    Backward: ∂J/∂d = d = −1.5; through + and − the slope passes unchanged, so ∂J/∂a = ∂J/∂c = −1.5 and ∂J/∂b = −1.5; ∂c/∂w = x, so ∂J/∂w = −1.5 × 1.5 = −2.25.

    A nudge check gives −2.25.

    Say it three ways
    In one line

    Store values going forward, multiply local slopes coming back.

    Like you are ten

    Going forward you write down every number. Coming back you ask each step ‘how much did you pass on?’ and multiply.

    forward passworking out every value from left to right
    backward passworking out every slope from right to left

    Spot the errorThis working looks right and is not. Find the exact line that fails before you open the answer — this is the skill a quiz distractor tests.

    For the same graph, a student writes:

    ∂J/∂c = −1.5. Since c = wx, the local derivative is w, so ∂J/∂w = −1.5 × 2 = −3.

    Find the slip and give the right value.

    show me where it breaks

    The local derivative of c = wx with respect to w is x, not w: nudge w by 1 and c moves by x. So ∂J/∂w = −1.5 × 1.5 = −2.25, which matches the nudge check (−2.25).

    In one line

    For a product, the slope with respect to one factor is the other factor.

    Like you are ten

    If you buy x apples at w pounds each, one more pound per apple costs you x more pounds, not w.

  4. From quiz question 10 · backpropagation

    TransferA situation the lesson never showed. If the idea only works on the lesson's own example, you have memorised the example, not the idea.

    A network has 1,000,000 parameters and one forward pass takes 0.01 seconds. How long does one gradient take if you estimate every derivative by nudging each weight up and down (two forward passes per weight)? How long with backprop (about one forward plus one backward pass)?

    compare with my answer

    Nudging: 2 × 1,000,000 × 0.01 s = 20,000 s, about 5.6 hours, for one update.

    Backprop: about 0.02 s. Nudging is still useful for one thing: checking a hand-written backprop on a few weights.

    Say it three ways
    In one line

    Backprop's cost does not grow with the number of weights the way nudging does.

    Like you are ten

    Checking every light bulb in a stadium one by one takes all night. A map showing which wire feeds which bulb tells you at once.
