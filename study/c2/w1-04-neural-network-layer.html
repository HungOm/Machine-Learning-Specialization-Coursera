7.4Neural network layer

The unit of construction. A layer is several neurons reading the same inputs and each producing one number — and the notation that goes with it.

C2 · Week 1 · lesson 4 of 1677 of 177 · 44% of the book

❓Before you read

A layer has 3 units and receives 2 numbers. How many numbers come out — and how many parameters does that layer hold? Commit to both.

I have committed to an answer

Three out; 2×3 weights + 3 biases = 9. Watch for the rule, because you will be asked to count parameters constantly.

🎈The idea, in plain words

In plain English

One neuron gives you one opinion. A layer is a panel of judges: they all watch the same performance, but each cares about different things — one watches the footwork, one the music, one the smile. Each judge holds up one score card. The layer’s output is the row of score cards.

Then the next layer is another panel that only sees the score cards, not the original performance.

🔧If you have never seen a formula

A kitchen brigade. The commis does one thing to everything that arrives: peels it. The sauce chef does one thing. The pass does one thing.

Every station does its identical job to whatever is put in front of it and slides the result along. Nobody at any station knows what the finished plate looks like. The dish is what comes out of the last station, and no single person made it.

🌉If you know a neighbouring field

Think of it as a function composition: f(g(h(x))), where each function is affine-then-nonlinear.

If you have chained matrix transformations in graphics, or composed steps in a data pipeline, this is that — with the one twist that each stage's coefficients are learned rather than specified.

👁One thing to picture

A column of numbers going in, and a shorter column coming out.

Four numbers in, three out. That is a layer: a machine that turns one vector into another vector, with the length usually changing. The notation a[1] = g(W[1]a[0] + b[1]) says nothing more than that.

⚖️Where this really costs something

The superscript-in-square-brackets convention is worth ten minutes now because it is used identically in every paper, framework and codebase you will ever read.

[l] is the layer, (i) is the example, and confusing the two produces shape errors that are genuinely painful to debug — the arithmetic runs, the numbers are wrong, and nothing raises.

So a layer is one function, applied to a vector, producing a vector. The whole network is that, repeated.

🔢The maths, decoded

For a layer with three units, reading a two-number input:

three units, three separate weight vectors, one shared inputa1[1] = g(w1[1]·x + b1[1])
a2[1] = g(w2[1]·x + b2[1])
a3[1] = g(w3[1]·x + b3[1])
collect them into one vector — this is what the layer outputs — hover or click it
a[1] = [ a1[1]   a2[1]   a3[1] ]the layer's whole output
SymbolSay it out loudWhat it actually is
layer“a layer”A group of neurons that all receive the same input vector and each output one scalar.
w2[1]“w two, layer one”The weight vector of the second unit of layer 1. Same length as the input.
a[1]“a one”The whole layer’s output, stacked: length = number of units in the layer.
units“units” / “neurons”Same thing. The Dense layer’s units=3 argument literally means “three of these”.
The one thing to remember

The number of units in a layer decides the length of that layer’s output vector. Nothing else. Not the number of inputs, not the number of examples. Just the width of what comes out.

🎬Watch it move

▶ One layer of three neuronsdrag x₁ and x₂ — each unit computes its own z, then its own a

Notice unit 2 has weights (−1.8, 2.2): it wants x₂ high and x₁ low. Unit 1 wants the opposite. Same inputs, opposite opinions — that variety is exactly what makes the next layer useful.

🧮One neuron, checked against Course 1

The first optional lab does something worth copying: it builds a single Keras neuron, sets its weights by hand to values you already know, and checks the answer against plain NumPy. First with no activation at all:

linear_layer = tf.keras.layers.Dense(units=1, activation='linear')
linear_layer.set_weights([np.array([[200]]), np.array([100])])   # w = 200, b = 100

Feed it the two houses from Course 1 and it returns 200(1) + 100 = 300 and 200(2) + 100 = 500 — the two prices, exactly. A neuron with no activation function is linear regression. Now add a sigmoid, with w = 2 and b = −4.5:

xz = 2x − 4.5a = g(z)decision at 0.5the label

Six for six. The boundary sits where z = 0, that is x = 4.5 / 2 = 2.25 — between the last 0 and the first 1. Notice the output never reaches 0 or 1; sigmoid only approaches them. 0.0110 means “almost certainly not”, and it is a probability, not a decision.

Say it out loud

Change b from −4.5 to −6 and the boundary moves to x = 3. Change w from 2 to 4 and the boundary stays at 2.25. Why does one move it and the other not?

said it — now check

The boundary is wherever z = 0, i.e. x = −b/w. The bias shifts every z up or down by the same amount, so the crossing point slides. The weight controls how fast z changes per unit of x — it makes the S steeper, so the neuron becomes more decisive near the boundary, but the place where it is undecided does not move unless b moves with it.

🕳Traps

Common trap

Thinking neurons in the same layer talk to each other. They don’t. Within a layer they are completely independent — that independence is exactly what lets us compute them all at once as a single matrix multiply in Lesson 15.

Common trap

Mixing up the two subscripts. a2[1] = unit 2 of layer 1. a[2] = the whole of layer 2. The position of the bracket carries the meaning.

✅Check yourself

A layer has 5 units and receives a 10-dimensional input. What comes out, and how many parameters?

Out: a vector of 5 numbers. Parameters: 10×5 = 50 weights + 5 biases = 55.

Does adding units to a layer change the number of inputs the layer accepts?

No. Units change the output width. The input width is fixed by whatever feeds it.

Why can the three units be computed in any order?

Because none of them depends on another’s output. They only depend on x. Independent work is parallelisable work.
