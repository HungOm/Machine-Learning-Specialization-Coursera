Problems — Reinforcement learning

Every number below comes from the six-state Mars rover in the lectures, so you can check any of them by hand. Get that tiny example completely solid and the lunar lander is the same ideas with a neural network bolted on.

How to use this page

Work each one on paper, with the solution shut. Open the hint only after you are genuinely stuck, and the solution only after you have written something down — even a wrong something. Reading a worked solution you have not attempted feels like learning and is not.

Then grade yourself honestly. A missed problem pulls that lesson’s review cards forward to tomorrow and shows up in weak spots.

1corethe return↗ lesson
The Mars rover lives on six states in a line. State 1 has reward 100, state 6 has reward 40, states 2–5 have reward 0. States 1 and 6 are terminal. The discount is γ = 0.5.
The rover starts in state 4 and always goes left. Write out the reward at each step and compute the return.
stuck? one hint
The return is R₁ + γR₂ + γ²R₃ + … The reward is collected on arrival, so the first term is the reward of the state you start in.
worked solution
  1. Path: 4 → 3 → 2 → 1rewards 0, 0, 0, 100
  2. Discount factorsγ⁰ = 1, γ¹ = 0.5, γ² = 0.25, γ³ = 0.125
  3. Multiply and add0(1) + 0(0.5) + 0(0.25) + 100(0.125)
  4. Result
    your turn12.5
answerreturn = 12.5
What this is really testingDiscounting is impatience made precise. That 100 is worth only 12.5 because it takes three steps to reach — and 0.5 is a very impatient discount.
2corecomparing actions↗ lesson
The Mars rover lives on six states in a line. State 1 has reward 100, state 6 has reward 40, states 2–5 have reward 0. States 1 and 6 are terminal. The discount is γ = 0.5.
From state 4, compute the return for going right as well, and say which action the rover should take.
worked solution
  1. Right: path 4 → 5 → 6rewards 0, 0, 40
  2. Discountsγ⁰ = 1, γ¹ = 0.5, γ² = 0.25
  3. Return0 + 0 + 40(0.25) = 10.0
  4. Compare with going left
    your turn12.5 versus 10.0
answerRight gives 10.0, left gives 12.5 — so the rover should go left, even though the 100 is further away.
What this is really testingThis is the whole trade-off in one comparison: a bigger reward further away versus a smaller one nearby. γ decides which wins, and it is a modelling choice you make.
3stretchhow gamma changes the answer↗ lesson
Redo the previous comparison with γ = 0.9 and with γ = 0.3. At which γ does the rover change its mind, and what does a small γ mean about the agent's character?
stuck? one hint
Left is worth 100γ³ and right is worth 40γ². Set them equal and solve for γ.
worked solution
  1. γ = 0.9: left = 100(0.9)³ = 100(0.729) = 72.9right = 40(0.81) = 32.4 → left
  2. γ = 0.3: left = 100(0.027) = 2.7right = 40(0.09) = 3.6 → right
  3. Set them equal: 100γ³ = 40γ²divide by γ²: 100γ = 40
  4. Solve
    your turnγ = 0.4
  5. Below γ = 0.4 the rover prefers the near reward
    your turnabove it, the far one
answerγ = 0.9 → left (72.9 vs 32.4); γ = 0.3 → right (2.7 vs 3.6). It switches at exactly γ = 0.4. A small γ makes the agent short-sighted: it will take a small reward now over a large one later.
What this is really testingγ is not a nuisance hyperparameter — it defines what the agent is trying to achieve. Change γ and you have changed the problem, not just the solution.
4stretchstate-action value↗ lesson
The Mars rover lives on six states in a line. State 1 has reward 100, state 6 has reward 40, states 2–5 have reward 0. States 1 and 6 are terminal. The discount is γ = 0.5.
The optimal values are V* = [100, 50, 25, 12.5, 20, 40]. Compute Q(4, ←) and Q(4, →) using Q(s,a) = R(s) + γ maxa′ Q(s′, a′), and state the optimal action in state 4.
stuck? one hint
R(s) is the reward of the state you are leaving, which is 0 for state 4. Then add γ times the value of the state you land in.
worked solution
  1. Q(4, ←) = R(4) + γV*(3)0 + 0.5(25) = 12.5
  2. Q(4, →) = R(4) + γV*(5)0 + 0.5(20) = 10.0
  3. V*(4) = max of the twomax(12.5, 10.0) = 12.5 ✓ consistent
  4. The optimal action is the argmax
    your turnleft
answerQ(4,←) = 12.5, Q(4,→) = 10.0, and the optimal action is left.
What this is really testingQ is the answer to “what if I take this action once, then behave optimally forever after”. That is why the greedy policy — argmax over Q — is optimal.
5stretchBellman equation↗ lesson
Verify the Bellman equation V*(s) = maxa [ R(s) + γ V*(s′) ] at states 2, 3 and 5, given V* = [100, 50, 25, 12.5, 20, 40].
worked solution
  1. State 2: left → V*(1) = 100, right → V*(3) = 25max(0 + 0.5(100), 0 + 0.5(25)) = max(50, 12.5) = 50 ✓
  2. State 3: left → V*(2) = 50, right → V*(4) = 12.5max(0.5(50), 0.5(12.5)) = max(25, 6.25) = 25 ✓
  3. State 5: left → V*(4) = 12.5, right → V*(6) = 40max(0.5(12.5), 0.5(40)) = max(6.25, 20) = 20 ✓
  4. Every state agrees with the given V*
    your turnthe values are self-consistent
answerAll three check out: V*(2) = 50, V*(3) = 25, V*(5) = 20. The optimal policy is ← ← ← → — left everywhere except state 5.
What this is really testingBellman says a value equals one step of reward plus a discounted value. That single recursive fact is what lets you solve for all the values at once, and it is what the DQN loss is built from.
6corepolicy↗ lesson
Given V* = [100, 50, 25, 12.5, 20, 40] and γ = 0.5, write out the optimal policy π(s) for states 2–5, and explain why state 5 differs from its neighbours.
worked solution
  1. State 2: 0.5(100) = 50 vs 0.5(25) = 12.5←
  2. State 3: 0.5(50) = 25 vs 0.5(12.5) = 6.25←
  3. State 4: 0.5(25) = 12.5 vs 0.5(20) = 10← (only just)
  4. State 5: 0.5(12.5) = 6.25 vs 0.5(40) = 20
    your turn→
  5. State 5 is one step from the 40 but four steps from the 100
    your turnwith γ = 0.5, distance dominates size
answerπ = [←, ←, ←, →] for states 2–5. State 5 goes right because the 40 is one step away while the 100 is four — and γ = 0.5 halves the value at every step.
What this is really testingState 4 is the interesting one: 12.5 versus 10 is a narrow margin. That is the exact point where the two rewards balance, which is why it flipped at γ = 0.4 in problem 3.
7corestochastic environments↗ lesson
The rover's wheels slip: it goes the commanded way with probability 0.9 and the opposite way with probability 0.1. What changes in the definition of the return, and what does the agent now maximise?
worked solution
  1. With slipping, the same action from the same state gives different pathsthe return is a random variable
  2. You cannot maximise a random numberyou maximise its average
  3. So the objective becomes the EXPECTED returnE[R₁ + γR₂ + γ²R₃ + …]
  4. Bellman gains an expectation over where you land
    your turnQ(s,a) = R(s) + γ E[max Q(s′,a′)]
  5. Everything else — policies, value iteration, DQN — is unchanged in structure
    your turnjust averaged
answerThe return becomes a random variable, so the agent maximises the expected return E[R₁ + γR₂ + γ²R₃ + …]. Bellman gains an expectation over the landing state.
What this is really testingEvery real environment is stochastic. Adding the expectation is a small change on paper and the reason you must average over many episodes to evaluate a policy.
8stretchtraining a DQN↗ lesson
A DQN learns Q(s,a) with a neural network. Describe what x and y are for a single training example, and identify the strange thing about this supervised learning problem.
stuck? one hint
You are creating your own training targets out of the network's current guesses.
worked solution
  1. x is the state and action togetherx = (s, a)
  2. y is what Bellman says Q should bey = R(s) + γ max_{a′} Q(s′, a′)
  3. But Q on the right is the network's own current estimatethe target depends on the model being trained
  4. So the targets move as training proceeds
    your turna moving target
  5. Mitigations: a separate frozen target network, and soft updates
    your turnthe target changes slowly enough to be learnable
answerx = (s, a) and y = R(s) + γ maxa′ Q(s′, a′). The strange part: the label is produced by the network being trained, so the targets move as learning proceeds — which is why DQN needs a frozen target network and soft updates to be stable.
What this is really testingThis is the single biggest difference from supervised learning in Courses 1 and 2. There, y was given and fixed. Here you manufacture it, and it changes underneath you.
9coreepsilon-greedy↗ lesson
With ε = 0.05, an agent picks a random action 5% of the time. (a) Why not always pick the best known action? (b) Why not always act randomly? (c) Why does ε usually start high and decrease?
worked solution
  1. (a) early Q estimates are nearly random guessesalways-greedy locks onto whichever bad action was overestimated first
  2. An action never tried keeps its initial estimate forevernever corrected
  3. (b) always random never exploits what it has learntno improvement in behaviour
  4. (c) early on, the estimates are worthless so exploring is cheap
    your turnstart with ε near 1
  5. Later the estimates are good, so exploiting is worth more
    your turndecay ε to about 0.01
answer(a) Early Q values are almost random, so greedy behaviour locks onto an overestimated bad action and never revisits it. (b) Pure randomness never uses what it has learnt. (c) Start high because early estimates are worthless, and decay because later estimates are worth exploiting.
What this is really testingThis is the explore/exploit trade-off, and it has no equivalent anywhere in Courses 1 and 2 — because there, the data arrived without the model's help.
10corecontinuous states↗ lesson
The lunar lander's state is [x, y, ẋ, ẏ, θ, θ̇, l, r] — position, velocity, angle, angular velocity, and two leg contacts. Why can you not use a table of Q values here, and what replaces it?
worked solution
  1. Six of the eight numbers are continuousinfinitely many states
  2. Even discretising each into just 100 buckets100⁶ = 10¹² entries
  3. And you would need to visit each one many times to estimate itimpossible
  4. Replace the table with a function approximator
    your turna neural network
  5. The network generalises: states it has never seen but that resemble ones it has get sensible values
    your turnwhich a table can never do
answerContinuous states mean infinitely many entries — discretising six dimensions into 100 buckets each already gives 1012 cells. A neural network replaces the table and, crucially, generalises to states never visited.
What this is really testingGeneralisation is the real reason, not just size. A table has no opinion about a state it has never seen; a network interpolates.
11stretchreward design↗ lesson
The lunar lander's reward includes a large bonus for landing on the pad, a penalty for crashing, a small penalty for firing thrusters, and a small shaping term for moving towards the pad. Explain what each is for, and what would go wrong if you gave only the landing bonus.
worked solution
  1. Landing bonus defines the actual goalwhat success means
  2. Crash penalty rules out the fast wrong solutionotherwise crashing is neutral
  3. Fuel penalty encourages efficiencyand stops endless hovering
  4. Shaping term gives feedback on the wayprogress is rewarded, not just arrival
  5. With only the landing bonus, a random agent almost never lands
    your turnso it almost never sees a non-zero reward
  6. No signal means no gradient to learn from
    your turntraining stalls entirely
answerBonus = the goal · crash penalty = rule out the wrong solution · fuel penalty = efficiency · shaping = feedback along the way. With only the landing bonus the reward is almost always zero, because a random agent essentially never lands by accident — so there is nothing to learn from.
What this is really testingThis is the sparse reward problem, and reward design is most of the practical difficulty in real RL. A badly shaped reward produces an agent that games it perfectly and does the wrong thing.
12warm-upRL vs supervised↗ lesson
Give three concrete ways reinforcement learning differs from the supervised learning of Courses 1 and 2.
worked solution
  1. 1. No labelled correct action is ever providedonly a reward signal, often delayed
  2. 2. The agent's own actions determine what data it seessupervised data is fixed and independent of the model
  3. 3. Rewards can arrive many steps after the action that earned themcredit assignment across time
  4. A fourth: the agent must explore, deliberately taking actions it believes are worse
    your turnno supervised analogue
answer(1) There is no correct answer per example, only a reward. (2) The agent's actions decide what data it collects. (3) Rewards are delayed, so credit must be assigned back across many steps.
What this is really testingPoint (2) is why RL is so much harder in practice: a bad policy collects bad data, which trains a bad policy. Supervised learning has no such feedback loop.
