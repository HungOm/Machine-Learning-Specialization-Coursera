Problems — Regression, cost and gradient descent

The whole of Week 1 is one loop: predict, measure how wrong you are, step downhill, repeat. These problems make you run that loop by hand, which is the only way it stops being a slogan.

How to use this page

Work each one on paper, with the solution shut. Open the hint only after you are genuinely stuck, and the solution only after you have written something down — even a wrong something. Reading a worked solution you have not attempted feels like learning and is not.

Then grade yourself honestly. A missed problem pulls that lesson’s review cards forward to tomorrow and shows up in weak spots.

1warm-upthe model↗ lesson
A house-price model is f(x) = 0.2x + 50, where x is size in square feet and f(x) is price in thousands. Predict the price of a 1500 sq ft house, and say what w = 0.2 and b = 50 mean in plain words.
worked solution
  1. Substitute x = 1500f(1500) = 0.2 × 1500 + 50
  2. Multiply first0.2 × 1500 = 300
  3. Then add b
    your turn300 + 50 = 350
answerf(1500) = 350, i.e. $350,000. w = 0.2: each extra square foot adds $200. b = 50: the price a 0 sq ft house would cost — the line's starting height, not a meaningful house.
What this is really testingw is a rate and b is an offset. Every model in this specialization has this same pair, however many features there are.
2corecost function↗ lesson
Training set: (1, 1), (2, 2), (3, 3). For the model f(x) = 0.5x (so w = 0.5, b = 0), compute J(0.5, 0).
stuck? one hint
Four columns: x, prediction, error, error². Then sum and divide by 2m.
worked solution
  1. Predictions with w = 0.5f(1)=0.5, f(2)=1.0, f(3)=1.5
  2. Errors, prediction minus target0.5−1 = −0.5,   1−2 = −1,   1.5−3 = −1.5
  3. Squares0.25, 1, 2.25
  4. Sum
    your turn3.5
  5. Divide by 2m with m = 3
    your turn3.5 ÷ 6
answerJ(0.5, 0) ≈ 0.583
What this is really testingNote the perfect model here would be w = 1, giving J = 0. Cost measures how wrong a particular choice of w and b is — it is a score for the line, not for the data.
3corecost intuition↗ lesson
Same data (1,1), (2,2), (3,3). Compute J(1, 0) and J(1.5, 0). What do the three numbers (with J(0.5,0) ≈ 0.583 from the previous problem) tell you about the shape of J(w)?
worked solution
  1. w = 1: predictions are 1, 2, 3 — exactly the targetsall errors 0 → J = 0
  2. w = 1.5: predictions are 1.5, 3, 4.5errors 0.5, 1, 1.5
  3. Square and sum0.25 + 1 + 2.25 = 3.5
  4. Divide by 2m = 6
    your turn3.5 ÷ 6 ≈ 0.583
  5. Compare the three
    your turnJ(0.5) ≈ 0.583, J(1) = 0, J(1.5) ≈ 0.583
answerJ(1,0) = 0 and J(1.5,0) ≈ 0.583. The cost is a symmetric bowl with its lowest point at w = 1 — equally wrong in either direction.
What this is really testingThat bowl shape is why gradient descent works at all: from anywhere on it, downhill leads to the same single bottom. Squared error was chosen to guarantee this.
4coregradient descent↗ lesson
You are at w = 3, b = 1 with ∂J/∂w = 4 and ∂J/∂b = −2, and α = 0.1. Perform one update step. Show the new w and b.
stuck? one hint
The rule is: new = old − α × (its own derivative). Both updates use the OLD values.
worked solution
  1. w updatew = 3 − 0.1 × 4 = 3 − 0.4
  2. b update — note the minus of a minusb = 1 − 0.1 × (−2) = 1 + 0.2
  3. Both use the old w and b, computed before either changed
    your turnthis is what “simultaneous update” means
answerw = 2.6 and b = 1.2
What this is really testingUpdating w and then using the new w to compute b's gradient is the classic gradient-descent bug. It often still converges, which is why it survives so long.
5stretchthe gradient formulas↗ lesson
With data (1, 2), (2, 4) and current w = 0, b = 0, compute ∂J/∂w and ∂J/∂b using
∂J/∂w = (1/m) Σ (f(x(i)) − y(i)) x(i) and ∂J/∂b = (1/m) Σ (f(x(i)) − y(i))
stuck? one hint
With w = 0 and b = 0 every prediction is 0, so every error is just −y.
worked solution
  1. Predictionsf(1) = 0, f(2) = 0
  2. Errors (prediction − target)0−2 = −2,   0−4 = −4
  3. For ∂J/∂w, multiply each error by its own x(−2)(1) = −2,   (−4)(2) = −8
  4. Sum and divide by m = 2
    your turn(−2 + −8) ÷ 2 = −5
  5. For ∂J/∂b, just average the errors
    your turn(−2 + −4) ÷ 2 = −3
answer∂J/∂w = −5 and ∂J/∂b = −3. Both negative, so the update increases both w and b — correct, since the line starts flat at zero and needs to rise.
What this is really testingThe only difference between the two formulas is the extra x. That x is why features on wildly different scales produce wildly different gradients — the reason scaling matters.
6corelearning rate↗ lesson
You plot J against iteration number and see each of these. Diagnose each and say what to do:
(a) a curve that falls smoothly and flattens
(b) a curve that rises
(c) a curve that falls but is still falling steeply at the last iteration
(d) a curve that zig-zags up and down
worked solution
  1. (a) falling and flatteningworking, and converged — stop, or leave it
  2. (b) risingα too large — J should never increase. Try α ÷ 3
  3. (c) still falling steeplynot converged yet — run more iterations, or raise α
  4. (d) zig-zag
    your turnα too large: each step overshoots the bottom and lands up the far side. Reduce α
answer(a) converged  (b) α too big  (c) needs more iterations  (d) α too big
What this is really testingA rising J is never a data problem or a formula problem first — check α before you check anything else. Andrew Ng's advice: try 0.001, 0.01, 0.1, 1, each 3× the last.
7warm-upsupervised vs unsupervised↗ lesson
Label each as supervised regression, supervised classification, or unsupervised:
(a) predict tomorrow's temperature
(b) decide if a transaction is fraud
(c) group customers into segments nobody has defined
(d) predict how many days until a machine fails
worked solution
  1. (a) a number, from labelled historysupervised regression
  2. (b) one of two labels, from labelled examplessupervised classification
  3. (c) no labels at all — the groups are the outputunsupervised
  4. (d) a number again, even though it sounds like an event
    your turnsupervised regression
answer(a) regression (b) classification (c) unsupervised (d) regression
What this is really testingThe give-away is not the subject matter, it is: is there a right answer in the training data, and is that answer a number or a category?
8stretchtwo steps of gradient descent↗ lesson
Data: (1, 2), (2, 4). Start at w = 0, fix b at 0 (do not update it), and use α = 0.1. Run two steps of gradient descent on w. Is the cost going down?
stuck? one hint
Reuse the gradient from problem 5 for the first step. Then recompute it with the new w — it changes every step.
worked solution
  1. Step 1 gradient (from problem 5, with w = 0)∂J/∂w = −5
  2. Step 1 updatew = 0 − 0.1(−5) = 0.5
  3. Step 2: predictions with w = 0.5f(1) = 0.5, f(2) = 1.0
  4. Errors0.5 − 2 = −1.5,   1.0 − 4 = −3.0
  5. Times x, summed, ÷ m[(−1.5)(1) + (−3.0)(2)] ÷ 2 = (−1.5 − 6.0) ÷ 2 = −3.75
  6. Step 2 update
    your turnw = 0.5 − 0.1(−3.75) = 0.875
  7. Cost check: J(0) = (4 + 16)/4 = 5; J(0.5) = (2.25 + 9)/4 = 2.8125; J(0.875) = (1.265625 + 5.0625)/4 ≈ 1.582
    your turn5 → 2.81 → 1.58
answerw = 0.5 then w = 0.875, with cost falling 5 → 2.81 → 1.58. It is heading for w = 2, where the fit is exact.
What this is really testingNotice the steps get smaller as you approach the bottom, without α changing. The gradient shrinks on its own — that is why a fixed learning rate still converges.
9corereading a contour plot↗ lesson
On a contour plot of J(w, b), you see tight concentric ellipses. (a) Where is the best model? (b) What does a very stretched, thin ellipse tell you? (c) Which direction does gradient descent step in?
worked solution
  1. (a) contours are lines of equal cost, like height on a mapthe innermost ring is the minimum
  2. (b) stretched contours mean cost changes fast one way and slowly the otherfeatures on very different scales
  3. (c) the gradient points straight uphill, so the step goes straight downhill
    your turnperpendicular to the contour line
answer(a) the centre of the innermost ellipse  (b) badly scaled features  (c) perpendicular to the contour, downhill
What this is really testingA thin valley is exactly what makes gradient descent zig-zag: it keeps bouncing across the narrow direction while creeping along the long one. Scaling makes the ellipse circular and the path direct.
10corecost vs error↗ lesson
Why does the cost function square the errors instead of just adding them up? Give two distinct reasons, using errors of +3 and −3 as an example.
worked solution
  1. Plain sum3 + (−3) = 0 — a terrible model scores perfectly
  2. Squares cannot cancel9 + 9 = 18 — the badness survives
  3. Second reason: squaring makes J a smooth bowl with one minimum, so the derivative exists everywhere and downhill always leads to the same place
    your turnabsolute values give a kink at zero
answer(1) Positive and negative errors would cancel, so a bad model could score 0. (2) Squaring gives a smooth, single-minimum bowl that is easy to differentiate and safe to descend.
What this is really testingThe ½ in front is a third, smaller convenience: it cancels the 2 that comes down when you differentiate the square, leaving a tidy gradient.
11stretchunits and interpretation↗ lesson
Two people fit the same house data. One uses size in square feet and gets w = 0.2. The other uses size in thousands of square feet. What w should the second person get, and what does that tell you about comparing w values between models?
stuck? one hint
If x is divided by 1000, then to keep w·x the same, w must be multiplied by 1000.
worked solution
  1. First model, 1500 sq ft0.2 × 1500 = 300
  2. Second model sees x = 1.5w × 1.5 must also be 300
  3. Solve
    your turnw = 300 ÷ 1.5 = 200
answerw = 200. A weight's size means nothing on its own — it depends entirely on the units of its feature.
What this is really testingThis is why you cannot rank feature importance by comparing raw weights, and part of why regularization is only fair after scaling: it penalises big weights, and “big” is a statement about units.
12warm-upnotation↗ lesson
In the standard notation, what does each of these mean? m, x(i), y(i), ŷ, fw,b(x)
worked solution
  1. mhow many training examples there are
  2. x(i)the input of the i-th example — the bracketed i is an index, not a power
  3. y(i)the true output of the i-th example
  4. ŷ (“y hat”)
    your turnthe predicted output
  5. f_{w,b}(x)
    your turnthe model — a function of x, with w and b as its settings
answerm = number of examples · x(i), y(i) = the i-th input and its true answer · ŷ = the prediction · fw,b(x) = the model itself.
What this is really testingThe superscript in brackets is an index. Reading x⁽²⁾ as “x squared” makes every formula in the course incomprehensible, and it is a very easy mistake to make.
13corewhen linear fails↗ lesson
You fit a straight line and get a large cost that will not improve however long you train. The learning-rate plot looks healthy — J falls smoothly and flattens. What are the two possible explanations, and how would you tell them apart?
worked solution
  1. Explanation 1: the relationship is not straighta line cannot fit a curve, however well you optimise it
  2. Explanation 2: the features do not carry the informationno function of these inputs predicts y well
  3. How to tell: plot predictions against actuals, or residuals against xa pattern in the residuals means a shape you have not modelled
  4. A curved residual pattern points at explanation 1
    your turnadd polynomial features
answerEither the true relationship is curved (fix: polynomial or engineered features) or the features are uninformative (fix: get better features). Plot the residuals against x — a visible curve means the first, formless scatter means the second.
What this is really testingGradient descent converging tells you it found the best line. It says nothing about whether a line was ever the right thing to look for.
