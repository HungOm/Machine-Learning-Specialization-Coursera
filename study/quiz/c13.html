Classification

Logistic regression, the decision boundary, logistic loss and regularization. Watch the questions that ask what a number means — that is where the graded quiz concentrates.

  1. why not linear regression

    Why is linear regression a poor choice for a binary classification problem?

    • A probability must live in [0, 1] and a straight line does not. It also means one distant point can rotate the line and change predictions for cases whose data did not change at all.

    • It trains perfectly well. The problem is that what it converges to does not answer the question.

    • Speed is not the issue — logistic regression costs essentially the same to train.

    • Neither model requires that. It is the target that is categorical here, and that is precisely the mismatch.

  2. sigmoid

    The sigmoid g(z) = 1/(1 + e−z). What is g(0), and what happens as z becomes very large and negative?

    • At z = 0 the exponential is 1, giving 1/2. As z → −∞ the exponential explodes, so the fraction goes to zero. z = 0 is exactly the decision boundary.

    • The sigmoid never leaves (0, 1) — it cannot be negative. You may be thinking of tanh, which ranges −1 to 1.

    • g(0) = 1/(1+1) = 0.5, not 1. The function reaches towards 1 only for large positive z.

    • The output is a probability and is bounded below by 0. It is z, the input, that runs to −∞.

  3. reading the outputselect all that apply

    A logistic model outputs 0.3 for a patient. With the standard 0.5 threshold, which are true?

    • 0.3 is below the threshold, so the model predicts the negative class.

    • That is what the output is — an estimated probability, which is more information than the class alone.

    • 0.3 is above 0.25. The threshold is a choice made after training, and moving it trades precision against recall — the subject of C2 W3.

    • It is 70% confident in its prediction of class 0. The output is the probability of class 1, not a confidence in whatever it decided.

    • Nothing here says what the true label is. A probability is not right or wrong on a single case.

    What this is really testingThe output is P(y = 1). The class is what you get after applying a threshold you chose.

  4. logistic loss

    Why is squared error not used as the cost for logistic regression?

    • That is the technical reason. The logistic loss is chosen specifically to restore convexity, so there is a single minimum and descent from anywhere reaches it.

    • Squared error is a square — it cannot be negative. That is not the problem.

    • It is perfectly differentiable. It simply has a bad shape.

    • Computation cost is essentially identical. The issue is the geometry of the surface, not the arithmetic.

    What this is really testingConvexity is the property that makes “descend from anywhere” a safe strategy.

  5. the loss curve

    For a single example with y = 1, the loss is −log(f). What happens as f approaches 0?

    • −log(f) → ∞. Being confidently and completely wrong is infinitely expensive, and that is the whole design — it is what stops the model claiming certainty it has not earned.

    • That happens when f approaches 1 — the model was confident and right. You have the direction reversed.

    • The logistic loss is not bounded above. There is no ceiling to be approached.

    • log of a number below 1 is negative, and the leading minus sign flips it positive. The loss is always ≥ 0.

    What this is really testingThe infinity is real, which is why implementations clip f away from exactly 0 and 1.

  6. overfitting

    Which of these describes overfitting?

    • The model has fitted the noise in the examples it saw. That gap between training and unseen performance is the definition.

    • That is underfitting, or high bias — the model is not capable enough to capture the pattern in the first place.

    • That is the goal. Nothing is wrong.

    • That is an optimisation problem — usually the learning rate — and is unrelated to how well the fitted model generalises.

  7. regularization

    You increase λ substantially. What happens?

    • A larger penalty shrinks the weights, making the model less flexible. It fits the training data less well by design, and generalises better up to a point — after which it underfits.

    • You cannot have both. Regularisation buys reduced variance by giving up training fit — that is the trade.

    • Cross-validation error is U-shaped in λ: it falls, reaches a minimum, then rises as the model becomes too rigid.

    • Scaling affects how evenly the penalty is applied across features, but λ has a strong effect either way.

    What this is really testingThe U-shaped CV curve against λ is the picture to memorise. It reappears everywhere.

  8. what gets regularized

    In the regularized gradient, why is b normally left out of the penalty?

    • Shrinking b towards zero just biases every prediction downwards for no benefit. The penalty exists to stop individual features having outsized influence, and b is not attached to a feature.

    • b is generally non-zero and is genuinely needed — it is what lets the line sit at the right height.

    • It would remain convex. It would simply be a worse model.

    • It is learned, with its own partial derivative, exactly like every weight.

  9. the update rule

    Comparing the gradient descent update for logistic regression with the one for linear regression, what is true?

    • Both are (f − y)xj, averaged. In one, f is a dot product; in the other, a sigmoid of a dot product. This is not a coincidence — it holds for any generalised linear model with its canonical link.

    • The sigmoid's derivative cancels exactly against the log in the loss. That cancellation is why the final expression is so clean.

    • It can, and the same diagnostics for choosing α apply unchanged.

    • It has a bias term, updated the same way.

    What this is really testingOne implementation of the update serves both models. Only f changes.

  10. fixing overfittingselect all that apply

    Your model fits the training data almost perfectly but does badly on new data, and collecting more data is not possible this quarter. Which are reasonable next steps?

    • Directly targets variance by shrinking the weights, and keeps every feature. It is the usual first move for exactly this situation.

    • Fewer parameters means less capacity to memorise. It works, and it discards information permanently — which is why regularisation is generally preferred.

    • Same idea as removing features: a lower-degree model is less flexible and less able to chase noise.

    • That increases flexibility and makes overfitting worse. It is the fix for the opposite problem.

    • The model already fits the training data almost perfectly. More iterations move it further in the wrong direction.

    What this is really testingSymptom first, then remedy. High variance and high bias take opposite actions.
