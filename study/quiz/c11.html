C1 · Week 1 · 10 questions · pass mark 80%

Introduction to Machine Learning

Regression, the cost function and gradient descent. If you can do these ten closed-book you are ready for the graded quiz; if you cannot, the misses will tell you which lesson to re-read.

Closed book. No notes, no scrolling back — that is the condition the real one is sat under.
—

  1. supervised vs unsupervised

    A hospital wants to predict, from a patient's records, how many days they will stay. Which best describes this problem?

    • Past patients come with their actual length of stay — that is the label — and the answer is a number on a continuous scale. Both halves of the definition are satisfied.

    • Classification predicts one of a small set of categories. “Number of days” is a quantity, and treating 3 days and 4 days as unrelated categories throws away the ordering.

    • Clustering has no labels at all. Here the historical records do carry the right answer, so using an unsupervised method would discard the most valuable column you have.

    • Anomaly detection asks “is this unusual?”, not “how many days?” It is the right tool when you have almost no labelled examples of what you are looking for.

    What this is really testingTwo questions, in order: are there labels, and is the answer a number or a category?

  2. the model

    For f(x) = 0.3x + 12, what is the predicted value at x = 40?

    • 0.3 × 40 = 12, and 12 + 12 = 24. Multiply before you add.

    • This adds w and b and ignores x entirely. Check that x actually appears in your arithmetic.

    • This is 40 + 12 — it uses x but drops the weight. w is a rate: it says how much f changes per unit of x, so it must multiply x rather than be added to it.

    • This is 0.3 × (40 + 12) — the bias added inside rather than outside. b shifts the whole line up, so it is added last.

  3. cost functionselect all that apply

    Which of the following are true of the squared error cost J(w, b) for linear regression?

    • Every term is a square, and a sum of squares cannot be negative. J = 0 exactly when the line passes through every point.

    • That is what the cost function is for: it converts “which line?” into “which (w, b) makes this number smallest?”

    • Squared error in a linear model is convex — a bowl. There are no local minima to get trapped in, which is why gradient descent is safe here and not in a neural network.

    • That is one term inside the sum. J averages over all m examples — a cost for the whole dataset, not for one point.

    • This is exactly the overfitting trap you meet in Week 3. J is measured on the training set, and driving it to zero can make new predictions worse.

    What this is really testingJ scores a whole line with one number. The division by 2m is convention, not meaning.

  4. gradient descent

    Gradient descent is at a point where the derivative ∂J/∂w is negative. What happens to w on the next step?

    • The update subtracts α times the derivative. Subtracting a negative number increases w — and a negative slope means J falls as w rises, so increasing w is downhill. Correct.

    • This is the trap. The rule is subtract α∂J/∂w, and the derivative is negative, so the subtraction adds. Substitute a number: w − 0.1 × (−4) = w + 0.4.

    • w is unchanged only when the derivative is exactly zero, which is the definition of being at a minimum (or a flat point).

    • The two parameters are updated independently, each from its own partial derivative. b's value does not enter w's update rule.

    What this is really testingOne rule handles both directions because the sign is carried by the derivative.

  5. learning rate

    Your cost J increases on almost every iteration of gradient descent. What is the most likely cause?

    • The classic symptom. Each step overshoots the minimum and lands somewhere the slope is even steeper, so the next step is worse again. Try α ten times smaller.

    • A too-small α makes J fall very slowly. It still falls — it never rises.

    • More data changes what the minimum is, not whether the algorithm can walk downhill. A rising cost is an optimisation failure, not a data problem.

    • For linear regression with squared error it always is. A non-convex surface would cause you to land in a poor local minimum, not to climb.

    What this is really testingA rising cost is almost always α. Set it absurdly small to confirm the gradient itself is right.

  6. contour plots

    On a contour plot of J(w, b), what do the points on a single contour line have in common?

    • A contour is a level set — every (w, b) on that ring produces the identical value of J, in the same way every point on one elevation line of a map is at the same height.

    • Different (w, b) pairs on the same contour are different lines, and they generally predict different values. They merely happen to be equally wrong overall.

    • Only if the contours were perfect circles. Elongated ellipses — which is the usual case with unscaled features — have points on one ring at very different distances from the centre.

    • The gradient is zero only at the centre. Along a contour the gradient is non-zero and points perpendicular to the line.

  7. unsupervised learning

    Which of these is an unsupervised learning problem?

    • No labels exist and none are supplied — the groups are discovered from the data. That is clustering, and it is unsupervised.

    • Every historical day comes with the temperature that actually followed. Those are labels, so this is supervised regression.

    • The word “labelled” settles it. This is supervised classification.

    • The historical sale prices are the labels. Supervised regression.

    What this is really testingOne test: does the training data contain the answer you want to predict?

  8. simultaneous update

    Why must w and b be updated simultaneously?

    • The gradient describes the slope of J at the point you are currently standing on. Update w first, and b's gradient is then computed on a surface at a different point — you are descending a hill you have already partly moved down.

    • It will not crash. That is what makes this bug dangerous: it runs, it usually still converges, and it converges to something slightly wrong.

    • They are independent parameters with entirely different meanings — a slope and an intercept.

    • α is a fixed number you chose. Nothing about the update order changes it.

    What this is really testingA bug that still converges — to the wrong place — is worse than one that crashes.

  9. convergence

    You plot J against iteration number and the curve falls steeply, then flattens completely for the last 200 iterations. What does this tell you?

    • A flat tail means the parameters have stopped changing meaningfully. Running longer will not improve the fit — whether the fit is good is a separate question this plot cannot answer.

    • A too-small α gives a curve that is still falling at the right-hand edge. This one has flattened, which is the opposite diagnosis.

    • This plot only shows training cost against iterations. Overfitting is a gap between training and unseen data, and nothing here measures unseen data.

    • Convergence says the optimiser finished. It says nothing about whether the model is powerful enough — for that you would compare J to a baseline.

  10. interpreting parameters

    In f(x) = wx + b for house prices in thousands, with x in square feet, what does w mean?

    • w is a rate: the change in output per unit change in input. If w = 0.2 and price is in thousands, each extra square foot adds £200.

    • That would be the model's output at the mean x, which is w̄x + b — it involves both parameters, not w alone.

    • That is b, the intercept — the value of f when x = 0. It is often physically meaningless and still necessary, because it sets the line's height.

    • Accuracy is measured by the cost J, or by error on unseen data. A large w means a steep line, not a good one.

    What this is really testingw is a rate, b is an offset. Every model in the specialization has this pair.
