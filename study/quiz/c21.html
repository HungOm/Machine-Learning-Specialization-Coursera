C2 · Week 1 · 10 questions · pass mark 80%

Neural Networks

Layers, forward propagation, TensorFlow shapes and matrix multiplication. Half the marks on the real quiz for this week are shape questions, so most of these are too.

Closed book. No notes, no scrolling back — that is the condition the real one is sat under.
—

  1. counting parameters

    A hidden layer has 4 inputs and 3 units. How many parameters does it have?

    • 12 weights (4 inputs × 3 units) plus 3 biases, one per unit. Weights are inputs × units; biases match the unit count.

    • This counts the weights and forgets the biases. Every unit has its own bias.

    • This adds inputs and units rather than multiplying. Each unit needs a weight for every input.

    • This looks like 4×3 plus 3×3. Only one weight matrix is involved in one layer.

  2. what a unit does

    What does a single unit in a hidden layer compute?

    • Exactly logistic regression, if the activation is a sigmoid. A layer is several of these run side by side on the same inputs — no new idea, just repetition.

    • An average is a weighted sum with all weights equal to 1/n. A unit learns its weights, and they are rarely equal.

    • That is a max-pooling operation, which appears in convolutional networks and is not what a dense unit does.

    • That describes softmax, which acts on a whole layer's outputs at once. A single unit produces one number.

  3. TensorFlow shapes

    In TensorFlow, why must a single example be written [[200, 17]] rather than [200, 17]?

    • The library expects a 2-D array of rows. One example is a table with one row — slightly absurd for a single case, and the reason nothing has to change for a million.

    • The number of features is the second dimension. The extra bracket is about rows, not columns.

    • The dtype is unrelated. The requirement is about rank — how many dimensions the array has.

    • It is needed for both. This is one of the most common first-day errors, and it appears at prediction time as often as in training.

  4. matrix shapes

    What is the result shape of multiplying a (3×2) matrix by a (2×4) matrix?

    • Write the shapes side by side, check the touching pair agrees (2 and 2), and cross them out. What remains — 3 and 4 — is the answer.

    • This keeps the inner dimensions, which are exactly the ones that cancel.

    • The right shape, transposed. Order matters: the first matrix supplies the rows.

    • It is defined precisely because the inner dimensions match. It would be undefined if they did not.

    What this is really testingCheck the shapes on paper before writing the code. It removes most shape bugs in advance.

  5. forward propagationselect all that apply

    Which are true of forward propagation?

    • One direction, one pass. Each layer's output becomes the next layer's input.

    • A layer knows nothing about the layers beyond it, or about the loss. That locality is what makes stacking work.

    • Training runs it and then computes gradients; prediction runs it and stops. It is the same computation.

    • That is the backward pass and the optimiser. Forward propagation only evaluates — it changes nothing.

    • No labels are involved. That is why it works at prediction time, where no label exists.

  6. counting layers

    A network is described as having 4 layers. By the usual convention, what does this mean?

    • Hidden layers plus the output layer are counted; the input is not a layer because it computes nothing — it is just the data.

    • That would be a 5-layer network by the standard count.

    • This counts the input layer, which the convention excludes.

    • Layers and units are different things. A layer's width is its unit count.

  7. the Dense layer

    What does Dense(units=3, activation='sigmoid') create?

    • That one line is W, b and the activation, all three. The input width is inferred from whatever you feed it.

    • units is the number of outputs. The input count comes from the previous layer.

    • One layer, three units within it. Stacking layers is what the list in Sequential does.

    • Each of the 3 units has a full weight vector, so with 4 inputs there are 12 weights and 3 biases.

  8. NumPy operators

    In NumPy, what is the difference between A @ B and A * B?

    • Two characters apart, entirely different operations — and both will run silently on compatible shapes, which is what makes the confusion dangerous.

    • They compute different things. @ is newer syntax for np.matmul, not for *.

    • Reversed. In MATLAB * is matrix multiply, which is a common source of this mix-up.

    • It works on any pair whose inner dimensions agree.

  9. weight layout

    You write your own layer and store W so that each unit's weights are a column. Why does the convention matter?

    • If the dimensions happen to be compatible, the arithmetic proceeds and the numbers are meaningless. Nothing raises, which makes it the classic silent failure of a hand-written layer.

    • NumPy has no opinion. It is a convention you must apply consistently, and this course uses columns for units.

    • Memory layout has some effect at very large scale, but that is not why the convention matters here.

    • The bias is a vector added by broadcasting; its orientation follows from the output shape.

  10. the brain analogy

    Which statement about the relationship between neural networks and the brain is most accurate?

    • A unit here is a weighted sum and a nonlinearity. A real neuron has thousands of synapses, its own chemistry, and timing that carries information. The metaphor was fruitful and it is not a description.

    • They do not, and no one working on them claims otherwise. Computational neuroscience uses quite different models.

    • This is exactly the extrapolation the AGI lesson warns against. Rapid progress on narrow tasks is not evidence about a different category of capability.

    • Too strong. It motivated the architecture and still supplies useful intuition — it simply must not be mistaken for a claim about biology.
