13.14Algorithm refinement: ε-greedy policy

If you only ever do what you currently believe is best, you never discover that you were wrong.

C3 · Week 3 · lesson 14 of 16175 of 177 · 99% of the book

❓Before you read

Always take the action your current Q says is best. Guess what you might never discover — and what small change fixes it.

I have committed to an answer

Watch for the explore/exploit tension, and for what ε is doing about it.

🎈The idea, in plain words

In plain English

You always order the same thing at the restaurant because you know it is good. But there are forty other dishes and one of them might be better — you will never find out.

So make a rule: most of the time, order your favourite. Occasionally, order something random.

For the lunar lander this matters enormously. Its network starts with random weights, so it might believe firing the main engine is terrible. If it never tries, it never learns otherwise, and the belief never gets corrected.

🔧If you have never seen a formula

Always ordering the same dish at the same restaurant. It is good, you know it is good, and you will never discover the better one on the same menu.

So you make a rule: nine times out of ten order the usual, once in ten order something at random. You give up a little on average and you stop being permanently wrong about the menu.

🌉If you know a neighbouring field

The explore–exploit trade-off, and it is the same problem as A/B testing budget, clinical trial allocation, or any multi-armed bandit.

The insight that makes it non-obvious: acting greedily on a bad estimate is self-confirming. You never take the action you underrate, so you never gather the evidence that would correct the estimate. The error is stable.

👁One thing to picture

A coin flipped before every action. Heads with probability 1 − ε: take the best known action. Tails with probability ε: pick at random.

That is the entire algorithm. One extra line of code, and without it the agent gets stuck on the first mediocre strategy it happens to find.

⚖️Where this really costs something

The standard practice is to decay ε — start near 1.0 and fall to about 0.01 — so the agent explores early when its estimates are worthless and exploits later when they are not.

Getting the schedule wrong is a common and confusing failure: too fast and it locks onto a bad policy, too slow and it never stops behaving randomly. Both look like “the algorithm doesn't work”.

So the one random line below is what stops a confident agent being permanently wrong.

The one thing to remember

The exploration/exploitation trade-off is one of the genuinely fundamental problems in RL, and ε-greedy is the crudest possible answer to it. It works surprisingly well, which is why it is still the default.

🔬Why decay ε

Early on, Q is random noise. Following it greedily is pointless, so ε should be near 1 — explore almost everything.

Later, Q is genuinely informative. Random actions now mostly waste time and crash the lander, so ε should be small — but not zero, because there may still be corners of the state space you have not visited.

The assignment uses ε = 1.0 decaying multiplicatively to a floor of 0.01. Andrew notes something worth remembering: in reinforcement learning, a badly chosen hyperparameter does not merely slow you down by a factor of three the way it might in supervised learning — it can make the difference between learning and never learning at all. RL is genuinely more brittle.

🕳Traps

Common trap

ε = 0 from the start. The agent locks onto whatever its random initialisation happened to favour and never revises it. This is the single most common reason a DQN “does not learn”.

Common trap

ε staying at 1.0. Pure random play forever. It collects experience but never exploits what it learned, so performance never improves.

Say it out loud

ε = 0 from the start is “the single most common reason a DQN does not learn”. Say why the failure is self-sustaining rather than merely unlucky.

said it — now check

Because a greedy agent only ever takes the action it currently rates highest, so it only ever collects evidence about that action. The actions it underrates are never tried, so the underrating is never corrected.

The error is therefore stable: nothing in the loop can dislodge a bad initial estimate, and the agent locks onto whatever its random initialisation happened to favour. That is why the fix has to be forced randomness rather than more training.

✅Check yourself

Q = [12, 31, 24, 9] and ε = 0.05. What happens?

95% of the time it takes action 2 (Q = 31). 5% of the time it picks uniformly at random from all four — including action 2.

Why start at ε = 1.0?

Because at the start Q is random noise. Following it greedily is no better than random, and exploring widely gathers the varied experience the network needs.

Why not decay ε all the way to 0?

Because there may be states you have never visited whose Q estimates are still wrong. A small floor (0.01) keeps a little exploration alive indefinitely.

  3. From quiz question 5 · explore vs exploit

    Spot the errorThis working looks right and is not. Find the exact line that fails before you open the answer — this is the skill a quiz distractor tests.

    A team's reasoning for setting ε = 0 from the first step:

    1. The new network rates “fire main engine” at Q = −1.3 and “do nothing” at 6.8.
    2. Acting greedily wastes no steps on random actions.
    3. Every step trains the network on real rewards, so its estimates keep getting better.
    4. So the estimate for the main engine will be corrected too, given enough steps.

    Which line fails?

    show me where it breaks

    Line 4. Training only produces targets for actions that were actually taken. A greedy agent never fires the main engine, so no experience ever says what firing it is worth, and its low estimate stays low. Line 3 is true only for the actions it takes.

    That is the self-confirming error the quiz asks about. Exploration is how the missing evidence gets collected.

    Say it three ways
    In one line

    You cannot learn the value of an action you never take.

    Like you are ten

    You can practise your favourite trick a thousand times and still know nothing about a trick you have never tried.

    The words, in simple words
    self-confirminga belief that stops you collecting the evidence that would change it
    evidencereal results that show whether a guess was right
