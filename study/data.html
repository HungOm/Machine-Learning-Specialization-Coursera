Datasets

Every lesson on this site that says pd.read_csv('houses.csv') is reading a real file, and this is where it lives. Download it, or skip the download entirely — pandas reads a URL as happily as a path, so a one-line change makes any lesson runnable from a cold notebook.

The one line that saves you the download

Paste this at the top of a notebook and every snippet on this page runs, with nothing on disk:

import pandas as pd

DATA = 'https://raw.githubusercontent.com/HungOm/Machine-Learning-Specialization-Coursera/main/study/data/'

df = pd.read_csv(DATA + 'houses.csv')
df.shape        # (1000, 5)

Then pd.read_csv(DATA + 'houses.csv') anywhere a lesson says pd.read_csv('houses.csv').

The shapes below are measured off the files at build time, not written down — so a column table on this page cannot describe a file that no longer looks like that. Four of the seven are generated by datakit.py from a fixed seed, which is what lets the lessons quote an exact shape; the other three are the real Coursera data already in this repository, moved to one clean path.

Reading it

Why this file

houses_messy.csv

Pricefloat$ thousandsnote the capital P

Reading it

df = pd.read_csv('houses_messy.csv')

df.columns          # look here first — the names are not what you assumed
df.info()           # size is 'object', not int64. Why?
df.isnull().sum()   # floors 18, age 23

# the fix, once you have seen what is wrong
df.columns = df.columns.str.strip().str.lower()
df['size'] = pd.to_numeric(df['size'], errors='coerce')
df = df.dropna()
df.shape            # (956, 5)
Why this file

df['price'] raises KeyError — the column is spelled Price. df['beds'] raises it too — that one has a trailing space. size comes back as dtype object — four cells hold text, two of them numbers a spreadsheet helpfully wrote as 1,240 — so .mean() fails outright. And 41 cells are simply empty. df.columns, df.info() and df.isnull().sum() find all four in about ten seconds; the point of the file is to make that ten seconds a habit.

🔧Rebuilding them

The generated files are reproducible byte for byte — every generator draws from a seeded default_rng, so there is no reason to be precious about the copies in git:

python3 study/_build/datakit.py
python3 study/_build/build.py

The three course files are copied and reshaped from the notebooks in this repository rather than invented. The MovieLens pair is worth a note: pivoting ratings.csv back into a dense matrix reproduces the lab's own small_movies_Y.csv exactly — datakit.py asserts it every time the file is regenerated, so nothing is lost by keeping the twenty-times-smaller version.
